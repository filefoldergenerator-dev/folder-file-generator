# AI Folder & File Generator

Automatically generate complete project folder and file structures from a tree-based project layout and download them as a ZIP file.

---

## Overview

Developers often receive project structures from ChatGPT, AI tools, documentation, tutorials, or team leads and then manually create dozens of folders and files.

AI Folder & File Generator automates this process.

Simply paste a project structure, click Generate, and the tool creates the complete folder and file hierarchy instantly.

---

## Features

✅ Automatic Folder Creation

✅ Automatic File Creation

✅ Nested Folder Support

✅ Maintains Project Hierarchy

✅ ZIP File Generation

✅ One-Click Download

✅ Clean and Responsive UI

✅ Supports Large Project Structures
